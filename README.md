## GitHub Pages
1. Create a GitHub repository named `amman-pazhamudir-nilayam`.
2. Upload the contents of this folder directly into the repository root.
3. Go to Settings → Pages.
4. Select `Deploy from a branch`.
5. Select branch `main` and folder `/ (root)`.
6. Save and wait for the site to publish.

## Important URL note
A standard GitHub Pages URL includes the GitHub username, such as:
`https://USERNAME.github.io/amman-pazhamudir-nilayam/`

If you want a public URL containing only your shop name, such as:
`https://ammanpazhamudirnilayam.com`
you need to purchase/register that custom domain and connect it to GitHub Pages.
